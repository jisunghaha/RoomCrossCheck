# 게시글·댓글·반응

계획서: SFR-010

공지·자취 정보와 게시글·후기 대상 댓글·반응을 관리한다. 작성자·관리자 권한과 사용자별 반응 중복을 검증한다.

화면은 `pages/`, 해당 기능의 UI는 `components/`, React에 의존하지 않는 화면 계산은 `domain/`, 기능 상태는 필요할 때 `model/`에 둡니다. 서버 요청은 앱에서 주입한 저장소를 통해 수행합니다. 현재 없는 하위 폴더와 기능은 구현할 때 추가합니다.

서버 규칙과 연결: `backend/src/main/java/com/roomcrosscheck/community/` (저장소 루트 기준).
