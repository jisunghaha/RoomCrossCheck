# 광고 원본·개인 매물

계획서: SFR-002, SFR-004, SFR-009

임시 광고와 확정 매물을 구분하고 원본·사용자 확정값을 보존한다. 저장·목록·상세·선택 삭제와 소유권을 관리한다.

화면은 `pages/`, 해당 기능의 UI는 `components/`, React에 의존하지 않는 화면 계산은 `domain/`, 기능 상태는 필요할 때 `model/`에 둡니다. 서버 요청은 앱에서 주입한 저장소를 통해 수행합니다. 현재 없는 하위 폴더와 기능은 구현할 때 추가합니다.

서버 규칙과 연결: `backend/src/main/java/com/roomcrosscheck/listing/` (저장소 루트 기준).
