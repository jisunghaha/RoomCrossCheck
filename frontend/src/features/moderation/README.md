# 신고·관리자 처리

계획서: SFR-013

신고 대상·중복·상태·관리자 조치 이력을 관리한다. 숨김·복원을 해당 글·후기 기능의 유스케이스에 요청한다.

화면은 `pages/`, 해당 기능의 UI는 `components/`, React에 의존하지 않는 화면 계산은 `domain/`, 기능 상태는 필요할 때 `model/`에 둡니다. 서버 요청은 앱에서 주입한 저장소를 통해 수행합니다. 현재 없는 하위 폴더와 기능은 구현할 때 추가합니다.

서버 규칙과 연결: `backend/src/main/java/com/roomcrosscheck/moderation/` (저장소 루트 기준).
