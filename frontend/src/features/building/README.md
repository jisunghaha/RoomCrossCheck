# 건물 식별·공식 조회

계획서: SFR-005

확정 주소·동·호수로 건물·층·전유부를 식별한다. 공식 원본·출처·조회 시각과 조회 상태를 보존한다.

화면은 `pages/`, 해당 기능의 UI는 `components/`, React에 의존하지 않는 화면 계산은 `domain/`, 기능 상태는 필요할 때 `model/`에 둡니다. 서버 요청은 앱에서 주입한 저장소를 통해 수행합니다. 현재 없는 하위 폴더와 기능은 구현할 때 추가합니다.

서버 규칙과 연결: `backend/src/main/java/com/roomcrosscheck/building/` (저장소 루트 기준).
