# 건물별 후기·통계

계획서: SFR-011, SFR-012

건물에 연결한 8개 항목 평가와 공개 후기 통계를 관리한다. 미응답은 분모에서 제외하고 수정·삭제·숨김 시 캐시를 무효화한다.

화면은 `pages/`, 해당 기능의 UI는 `components/`, React에 의존하지 않는 화면 계산은 `domain/`, 기능 상태는 필요할 때 `model/`에 둡니다. 서버 요청은 앱에서 주입한 저장소를 통해 수행합니다. 현재 없는 하위 폴더와 기능은 구현할 때 추가합니다.

서버 규칙과 연결: `backend/src/main/java/com/roomcrosscheck/review/` (저장소 루트 기준).
