# 방문 이력·체크리스트

계획서: SFR-007

소유자만 접근 가능한 방문별 점검·사진·메모·확인 질문을 관리한다. 사용자 추가 항목은 안정적인 ID로 식별한다.

화면은 `pages/`, 해당 기능의 UI는 `components/`, React에 의존하지 않는 화면 계산은 `domain/`, 기능 상태는 필요할 때 `model/`에 둡니다. 서버 요청은 앱에서 주입한 저장소를 통해 수행합니다. 현재 없는 하위 폴더와 기능은 구현할 때 추가합니다.

서버 규칙과 연결: `backend/src/main/java/com/roomcrosscheck/visit/` (저장소 루트 기준).
