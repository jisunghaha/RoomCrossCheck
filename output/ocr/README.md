# OCR 테스트 예시

`sample-room-ad.png`는 OCR 수동 테스트용으로 생성한 가상 원룸 광고입니다. 실제 매물이나 주소를 나타내지 않습니다.

## 사용 방법

백엔드와 MySQL을 실행하고 프론트엔드를 `listing-api` 모드로 실행합니다. 서버 환경에 `GEMINI_ENABLED=true`와 `GEMINI_API_KEY`를 설정합니다. 키는 Git에 커밋하지 않습니다.

등록 화면에서 **광고 글·사진에서 가져오기**를 선택한 뒤 이 이미지를 업로드합니다. **광고 원본 임시 저장 → 원본 확정 → Gemini 추출 시작** 순서로 진행하고 아래 값과 비교합니다.

| 항목 | 기대 값 |
| --- | --- |
| 주소 | 서울특별시 테스트구 예시로 123, 301호 |
| 보증금 | 10,000,000원 |
| 월세 | 500,000원 |
| 관리비 | 50,000원 |
| 전용면적 | 20㎡ |
| 층수 | 3층 |

## 2026-11-03 로컬 검증 기록

- 백엔드 빌드 및 기존 테스트 통과.
- MySQL 및 Spring Boot 서버 실행 확인.
- 프론트엔드 프록시를 통한 API HTTP 200 응답 확인.
- Gemini 모델 목록 API 인증 및 기본 모델 접근 확인.
- 별도의 가상 글 광고로 추출 결과 `EXTRACTION_READY`와 금액·면적·층수 확인.
- 빈 테스트 PNG와 가상 글을 함께 업로드하여 이미지 첨부 요청도 `EXTRACTION_READY` 확인.
- Chrome 등록 화면에서 추출 결과 표시 확인.

위 연결 검증은 이 예시 이미지의 글자 인식 정확도를 검증한 결과가 아닙니다. `sample-room-ad.png` 자체의 OCR 정확도는 수동 확인이 필요합니다. 사용자가 보고한 `Failed to fetch` 오류는 점검 당시 재현되지 않아 원인을 확정하지 못했습니다. 애플리케이션 소스 코드는 변경하지 않았습니다.

이미지는 내장 이미지 생성 도구로 제작했습니다. 생성 요청은 밝은 원룸 사진과 선명한 한글 주소·보증금·월세·관리비·면적·층수를 포함한 가상 OCR 테스트 광고입니다.
