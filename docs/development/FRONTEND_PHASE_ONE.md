# 보고서 기반 프론트 1차 화면

현재 디자인과 기능별 폴더 구조를 유지하면서 등록·상세·공개 커뮤니티의 이동 흐름을 추가했다. 이번 작업은 프론트 화면과 로컬 시연 범위다. 백엔드·DB·실제 인증은 변경하지 않았다.

## 화면 진입

기본 주소는 `http://127.0.0.1:4173/`이다. 기존 탭에서 다른 화면을 보고 있다면 로고 또는 서비스 소개 메뉴로 첫 화면에 돌아간다.

| 주소 뒤 경로 | 화면과 동작 |
|---|---|
| `#home` | 서비스 소개, 등록·커뮤니티 바로가기 |
| `#login`, `#signup` | 일반 로그인·회원가입 입력 검증. 계정 생성·인증 성공으로 처리하지 않음 |
| `#rooms` | 기존 관심 매물과 임시 저장 매물 목록 |
| `#register` | 직접 입력 또는 사진 등록 선택 → 매물 정보 입력·검토 → 최종 확인·확정 저장 |
| `#register/{id}` | 임시 저장 매물의 등록 이어가기 |
| `#compare`, `#visits` | 기존 매물 비교·방문 체크리스트. 임시 매물은 제외 |
| `#community/notice` | 시연 공지 목록·검색 |
| `#community/tips` | 시연 자취 정보 목록·검색 |
| `#community/reviews` | 기존 건물 후기 목록·작성·통계 |
| `#post/{id}` | 시연 글 상세와 해당 분류 목록으로 돌아가기 |

기존 `#reviews` 주소도 커뮤니티 후기 탭으로 연결된다. 매물 상세 모달은 광고 정보·공식 대조·방문 기록·건물 후기 탭으로 나뉜다.

## 입력과 보존 범위

- 등록 방식은 직접 입력·사진 등록으로 나눈다. 기본은 직접 입력이며 사진과 광고 글을 요구하지 않는다. 사진 등록은 실제 이미지를 선택해야 진행할 수 있다. `registrationMethod`에 `manual`·`photo`를 보존하고, 직접 입력으로 전환하면 사진과 첨부명은 저장 대상에서 제외한다.

- 회원 폼의 비밀번호는 컴포넌트 입력 상태에만 존재한다. 브라우저 저장소로 보내지 않고, 유효한 입력 검증 후 지운다. 중복 아이디 검사·실제 회원 저장·세션 처리는 아직 없다.
- 등록 2단계까지는 저장하지 않는다. 뒤로 이동해도 입력을 유지한다. 임시 저장 또는 확정 저장에 성공했을 때 목록으로 이동한다. 실패 시 확인 화면과 입력을 유지한다.
- 로컬 매물에는 `status`의 `DRAFT`·`CONFIRMED`, `buildingDong`, `unitNumber`, `sourceUrl`, `attachmentName`을 선택 필드로 추가했다. 기존 데이터에 status가 없어도 확정 매물로 표시한다. 금액은 원 단위로 저장하고 0과 NULL을 구분한다.
- 광고 이미지 선택은 JPG·PNG, 10MB 이하의 미리보기만 제공한다. 실제 이미지와 이미지 URL은 저장하지 않으며 화면에 이 제한을 명시한다. 이미지 검증과 영구 파일 보관은 서버 연동 시 구현한다.
- 단계형 등록은 local 모드에서 제공한다. api 모드는 서버의 임시·확정 계약을 확장한 뒤 연결한다.
- 기존 localStorage 키를 유지한다. 임시 매물을 수정·확정하면 같은 ID를 사용하며, 일반 수정에서도 추가 원본 메타데이터를 보존한다.

## 시연과 실제 처리의 구분

OCR·공공 조회 결과를 임의로 생성하지 않는다. 기존 공식 예시는 시연 자료로 표시하고 미구현 항목은 대조 대기로 표시한다. 조회 상태와 항목별 대조 결과를 구분하며 계약 안전성을 보증하지 않는다.

커뮤니티 공지·자취 정보는 `app/data/communitySeed.js`의 가상 글이다. 글 작성·댓글·반응·신고·관리자 처리, 다중 방문 이력·사진 저장, 전체 대조 규칙·비교표 확장은 2차 범위다. 공개 후기의 실제 거주 사실은 인증하지 않는다.

## 파일 위치와 주석

`features/home`, `features/auth/pages`, `features/community/pages`, `features/listing/pages/RegisterRoomPage.jsx`에 새 화면을 추가했다. 기존 `app`의 레이아웃·해시 라우팅·화면 조합에서 연결하며, 추가 배치는 `app/report-phase-one.css`에 있다.

주석은 [팀 작성 기준](COMMENTS.md)에 따라 역할·제약·저장 경계를 한국어로 설명한다. JSDoc 형식은 해당 문서에 연결된 Google JavaScript Style Guide를 참고했다.

## 검증

`frontend`에서 `npm.cmd test`, `npm.cmd run build`를 실행한다. 기존 매물·후기·방문·API 오류 흐름과 함께 회원 입력 검증, 확정 전 미저장, 임시 저장 이어가기, 등록 단계 뒤로 이동, 커뮤니티·상세 탭 이동을 검증한다.
