# 실제 이미지 추출 응답 재생 검증

이 검증은 [단건 실제 Gemini 응답](image-001-result.json)의 `extraction`을 로컬 추출 서버에서 재생한다. 새로운 Gemini 호출이나 요금 설정 변경은 하지 않는다. 외부 Gemini 이미지 추출 성공 근거는 원래 HTTP 200 기록이며, 이번 실행은 그 응답을 애플리케이션에서 처리·저장하는 경로를 검증한다. 실시간 Gemini를 포함한 단일 브라우저 세션 검증이나 20건 정확도 평가 완료를 의미하지 않는다.

## 실행

Docker·Python·Node와 설치된 npm 의존성, Chromium이 필요하다. 관리형 환경은 기존 일반 실행 스크립트의 프록시·CA 설정을 사용하며, 백엔드 빌드에 Maven/Java Docker 이미지를 사용한다.

```sh
npm run test:browser:replay
```

원본 JPEG는 개인정보와 검증 산출물을 Git에 추가하지 않도록 `.runtime/sfr003-image-001/source.jpg`에 보관했다. 새 환경에서는 사용자가 제공한 **세 번째 원본 캡처**를 그 경로에 복원해야 한다. 실행기는 `image-001-result.json`의 SHA-256과 원본이 일치하는지 먼저 검사하고, 누락·불일치 시 실행을 중단한다. 이미지를 새로 만들거나 다른 캡처로 대체하지 않는다.

실행기는 임시 Compose 프로젝트·비밀번호·빈 MySQL·업로드 볼륨을 생성하고, 백엔드에는 검증용 가짜 키와 로컬 재생 서버 URL만 전달한다. 일반 앱 설정에 재생 모드를 추가하거나 실제 키를 저장하지 않는다. 기존 개발 DB를 사용하거나 삭제하지 않으며 실행한 임시 프로젝트만 종료·정리한다. 검증 후 앱 서버는 계속 켜져 있지 않다.

## 검증 내용

- 실제 JPEG만 브라우저에서 업로드하고 광고 글·주소 힌트는 비워 둔다. 백엔드가 추출 서버에 전달한 이미지 바이트의 SHA-256도 확인한다.
- `DRAFT → EXTRACTION_PENDING → EXTRACTION_READY → REVIEWED`를 거쳐, 사용자 확인 완료 전에는 매물 등록 연결 버튼을 제공하지 않는지 확인한다.
- 추출 대기 완료 상태의 중복 추출은 저장 결과를 재사용하고, 확인 완료 이후의 재추출은 HTTP 409로 차단하는지 확인한다. 로컬 재생 응답은 총 1회만 반환되어야 한다.
- 월세를 AI 500,000원 → 사용자 확인 510,000원 → 매물 폼 520,000원으로 수정한다. **51만원·52만원은 수정 보존 테스트용 값이며 실제 광고의 정답 50만원은 변경하지 않는다.**
- 등록 폼의 만원 변환·부분 주소·면적·해당 층·읽은 원문을 확인하고 최종 확인 이전 및 내용 수정 왕복 후 매물 수가 0인지 검사한다.
- 최종 저장 후 매물이 1건인지 확인하고, 새로고침·백엔드와 MySQL 재시작·새 브라우저 컨텍스트에서도 같은 자료를 읽는지 확인한다.
- API뿐 아니라 MySQL 직접 조회로 AI JSON·사용자 확인 JSON·최종 매물 값을 비교하고, 업로드 원본 파일도 재시작 전후 해시가 동일한지 확인한다.
- 공식 정보 필드를 만들지 않고 화면에 `공식 조회 미실시`가 표시되는지 확인한다. 동 단위 주소를 상세 주소로 확장하거나 건축물대장 검증값으로 취급하지 않는다.

결과는 [image-001-replay-result.json](image-001-replay-result.json), 화면 캡처와 상세 실행 로그는 `.runtime/sfr003-image-001/`에 남긴다. 기존 `browser-flow-result.json`과 smoke-002~006은 덮어쓰지 않는다. 실패 시 통과 결과로 간주하지 않으며 로그와 결과 상태를 함께 확인한다.

2026-10-16 실행 결과: **전체 통과**. 로컬 재생 1회·외부 Gemini 호출 0건, MySQL 직접 조회·백엔드/MySQL 재시작·새 브라우저에서의 재조회·원본 이미지 해시 보존을 확인했다. 최초 실행의 선택 상자 라벨을 찾는 테스트 선택자 오류는 수정했고 실패 로그를 별도 보존했다. 앱 UI·업무 API·DB 변경은 필요하지 않았다.

## 별도로 남은 사항

대표 광고 20건과 사람이 확인한 정답, OCR 원문 문자 오류율, 새로운 광고로 무료 조건을 확인한 실시간 Gemini 브라우저 흐름은 별도 검증 범위다. 이미 사용한 이 광고를 재호출해서 검증하지 않는다.

SFR-002의 업로드·확정 및 SFR-003의 추출·확인·등록 연결은 현재 개발용 `listings`·`advertisements` 모델을 사용한다. 팀 `rooms`와의 ID·실제 사용자 소유권·광고-매물 영구 연결·최종 등록 멱등성은 [팀 통합 계약 제안](TEAM_INTEGRATION.md)에 따라 합의가 필요하다. 로그인·가짜 사용자 ID·V1 migration 변경은 하지 않는다.
