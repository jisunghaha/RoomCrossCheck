# AI 추출 응답 검증과 실패 처리

첨부 일정표의 SFR-004(AI 기반 매물 정보 추출)에서 승인된 응답 검증·실패 안내만 보완했다. OCR 엔진 추가, 항목별 원문 근거 확장, 확인 화면 개편, 인증, 팀 DB 전환은 포함하지 않는다.

## 응답 계약

새 Gemini 응답은 JSON 객체이며 rawText·address·depositWon·monthlyRentWon·maintenanceFeeWon·areaSqm·floor 키가 모두 있어야 한다. 미기재 값은 키를 생략하는 대신 명시적인 null로 반환한다. rawText는 읽힌 광고 글을 담는 문자열이며 공백뿐이면 NO_READABLE_TEXT로 실패한다. 읽힌 글이 있고 개별 조건이 없는 경우의 null은 정상이며 0으로 대체하지 않는다.

주소는 문자열 또는 null, 금액·층수는 정수 또는 null, 면적은 숫자 또는 null이어야 한다. 숫자 문자열·금액/층수 소수·잘못된 옵션·뒤에 붙은 다른 JSON도 거부한다. 기존 범위·면적 종류·옵션 검증을 유지한다. areaType·options가 없던 응답의 호환성을 유지하며 기존 저장 JSON을 수정하지 않는다.

이 검증은 응답 구조와 범위를 확인한다. 실제 광고와 값이 일치하는지 또는 문장이 실제 이미지에 있는지까지 증명하지 않으며, 사용자 확인·수정은 계속 필요하다.

## 오류와 재시도

| code | HTTP | 의미 |
|---|---|---|
| CONFIGURATION_MISSING | 503 | 추출 비활성화 또는 키 미설정 |
| AUTHENTICATION_FAILED | 502 | 공급자 401·403 |
| RATE_LIMITED | 429 | 공급자 사용 한도 |
| PROVIDER_UNAVAILABLE | 502 | 기타 공급자 HTTP 오류 |
| TIMEOUT | 504 | 전송 시간 초과 또는 공급자 408·504 |
| CONNECTION_FAILED | 502 | 연결·전송 I/O 오류 |
| INVALID_RESPONSE | 502 | 누락 필드·잘못된 자료형·파싱 불가 응답 |
| NO_READABLE_TEXT | 502 | 읽힌 광고 글 없음 |
| INVALID_VALUES | 502 | 기존 값 범위 검증 실패 |
| SOURCE_UNAVAILABLE | 500 | 보관된 이미지 읽기 실패 |
| INTERRUPTED | 502 | 실행 중 요청 중단 |

API는 미리 정한 code·message만 제공하며 공급자 응답 본문·키·연결 예외를 그대로 반환하지 않는다. 화면도 알려진 code와 HTTP 조합만 안내한다. 알 수 없는 본문·HTML·프론트 연결 실패에는 안전한 기본 안내를 표시한다.

설정 미비는 추출 대기 상태를 유지한다. 나머지 실패는 EXTRACTION_FAILED와 안전한 실패 사유를 기록하며 원본·첨부 메타데이터를 보존한다. 실패를 EXTRACTION_READY로 저장하거나 누락값을 0으로 채우지 않는다. 성공한 재시도에서만 추출 JSON·시각을 저장하고 이전 실패 사유를 지운다. 자동 외부 재시도는 추가하지 않았다. 실패 코드의 별도 DB 컬럼은 추가하지 않았으며 재조회에는 기존 extractionError 안내가 유지된다.

## 검증

백엔드 36건·프론트 51건·실행 설정 6건과 Java/프론트 빌드를 통과했다. 실제 전송 시간 초과는 대기 시간을 소모하지 않는 HttpClient 대역으로 구분을 검증했다.

별도 MySQL 8.4와 로컬 응답 서버에서 빈 JSON·null·키 누락·잘못된 JSON·빈 인식문·숫자 문자열·범위 초과·잘못된 옵션·인증·사용 한도·공급자 시간 초과·공급자 장애·연결 종료의 13가지 실패를 재현했다. 실패 결과 미저장, 원본 보존, 동일 광고 재시도, null/0 구분을 확인했다. 구버전 추출 JSON은 API에서 호환되며 DB 원문은 바뀌지 않았다.

Chromium에서 빈 응답·시간 초과 안내, 실패 시 확인 폼 미표시, 원본 보존과 재시도 후 확인 폼 표시를 확인했다. 실패 상태의 재시작 보존과 재시작 후 재시도도 검증했다. 초기 브라우저 검증의 API 기준 URL을 수정한 뒤 전체 실행을 통과했다.

검증 기록·스크립트·화면은 `/workspace/reports/extraction-guard-20261104/`에 보관한다. 실제 Gemini 요청은 0건이며, 임시 DB·업로드 자료는 정리했다. 실제 AI 정확도나 SFR-004 전체 요구사항 완료를 주장하지 않는다.
